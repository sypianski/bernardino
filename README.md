# Bernardino

Aplikacja desktopowa do transkrypcji wywiadów badawczych na modelach lokalnych: znaczniki czasu, rozpoznawanie mówców, korekta niepewnych słów. Nagrania i teksty zostają na Twoim komputerze.

To repozytorium zawiera **tylko wydania** (instalatory dla macOS, Windows i Linuksa oraz pliki aktualizacji). Kod źródłowy jest na razie w prywatnym repozytorium.

## Pobieranie

Instalatory są w zakładce [Releases](../../releases/latest).

- macOS (Apple Silicon): plik `.dmg`
- Windows: plik `-setup.exe` (instalator nie jest jeszcze podpisany; przy ostrzeżeniu SmartScreen wybierz „Więcej informacji”, potem „Uruchom mimo to”)
- Linux: `.AppImage` albo `.deb`

Zainstalowana aplikacja sprawdza nowe wersje tylko na Twoje żądanie (O programie → Aktualizacje).
